# Rice + NASA POWER Weekly Merged Dataset

## Overview

This dataset combines **rice farm field records** (soil, nutrients, management, yield) with **location-specific NASA POWER weather data** aggregated into **Monday–Friday weekly windows** across each farm's growing season.

| Property | Value |
|----------|-------|
| **Output file** | `exports/rice_nasapower_weekly_wide.csv` |
| **Format** | Wide (one row per farm) |
| **Records** | 1,056 farms |
| **Columns** | 144 (28 farm + 116 weather) |
| **Geography** | UP, Bihar, Punjab, Haryana (994 unique lat/lon pairs) |
| **Sowing years** | 2012, 2014, 2015, 2022 |
| **Generated by** | `merge_rice_nasapower.py` |

## Dataset Structure

Each row represents **one rice farm record**. Weather is stored as **wide columns** — one set of 4 metrics per week of the growing season.

```
┌─────────────────────────────────────────────────────────────────────────┐
│  FARM FIELDS (28 cols)          │  WEEKLY WEATHER (116 cols)           │
│  ─────────────────────          │  ──────────────────────────           │
│  record_id, lat, lon             │  week01_rainfall_total_week_mm       │
│  sowing / harvest dates          │  week01_rainfall_weekly_mean_mm_day  │
│  yield, soil, nutrients, ...     │  week01_relative_humidity_...       │
│  season_days, total_mon_fri_weeks │  week01_solar_radiation_...         │
│                                  │  week02_*, week03_*, ... week29_*    │
└─────────────────────────────────────────────────────────────────────────┘
```

### Farm Columns (28)

| Column | Type | Description |
|--------|------|-------------|
| `record_id` | Integer | Unique record ID (1-based, after skipping duplicate header row) |
| `Longitude` | Float | Farm longitude (WGS84, decimal degrees) |
| `Latitude` | Float | Farm latitude (WGS84, decimal degrees) |
| `Crop Sowing Time` | Date | Sowing date (`YYYY-MM-DD`) |
| `Crop Harvesting Time` | Date | Harvest date (`YYYY-MM-DD`) |
| `Yield Level (t/ha)` | Float | Observed rice yield (tonnes/hectare) |
| `season_days` | Integer | Days from sowing to harvest |
| `total_mon_fri_weeks` | Integer | Number of Mon–Fri weeks in the growing season |
| `pH (1:2)` … `FYM input interval (Yr)` | Mixed | Soil, nutrient, and management fields from source |
| `Crop Sowing Time_1` | Integer | Sowing day-of-year (Julian) |
| `Crop Harvesting Time_1` | Integer | Harvest day-of-year (Julian) |

### Weekly Weather Columns (116 = 29 weeks × 4 metrics)

For each week `N` (01–29), four columns are provided:

| Column pattern | Unit | NASA parameter | Aggregation |
|----------------|------|----------------|-------------|
| `weekNN_rainfall_total_week_mm` | mm | `PRECTOTCORR` | Sum (Mon–Fri days only) |
| `weekNN_rainfall_weekly_mean_mm_day` | mm/day | `PRECTOTCORR` | Mean (Mon–Fri days only) |
| `weekNN_relative_humidity_weekly_mean_pct` | % | `RH2M` | Mean (Mon–Fri days only) |
| `weekNN_solar_radiation_weekly_mean_kwh_m2_day` | kWh/m²/day | `ALLSKY_SFC_SW_DWN` | Mean (Mon–Fri days only) |

**Blank values:** If a farm's growing season has fewer than `N` weeks, `weekNN_*` columns are empty (`NaN`).

**Week numbering:** Week 01 starts at the Monday of or before the sowing date. Each subsequent week advances by 7 calendar days (Mon–Fri window). Weeks stop when the Friday window no longer overlaps the harvest date.

## Usage Notes

1. **Per-location weather:** Each farm's weather is fetched using its own latitude and longitude, not a single shared weather station.
2. **Mon–Fri only:** Weekday aggregation excludes Saturday and Sunday from weekly totals and means.
3. **Wide format for ML:** The wide layout is suited for models that expect fixed feature columns per growth week (e.g., week1–week19 rainfall sequences).
4. **Missing weeks:** Always check `total_mon_fri_weeks` before using `weekNN_*` columns — columns beyond this count are intentionally blank.

## Example: Reading the Data

```python
import pandas as pd

df = pd.read_csv("exports/rice_nasapower_weekly_wide.csv")

# Farm with 19 growing-season weeks
farm = df[df["record_id"] == 1].iloc[0]
print(f"Sowing: {farm['Crop Sowing Time']}, Weeks: {farm['total_mon_fri_weeks']}")
print(f"Week 1 rainfall: {farm['week01_rainfall_total_week_mm']} mm")
print(f"Week 10 rainfall: {farm['week10_rainfall_total_week_mm']} mm")

# Get all rainfall columns for a farm
rainfall_cols = [c for c in df.columns if "rainfall_total_week" in c]
df[rainfall_cols].head()
```
